## 1. Amazonアソシエイト（日本）

### 登録手順
1. https://affiliate.amazon.co.jp にアクセス
2. Amazonアカウントでログイン（普段使っているものでOK）
3. ブログURLを求められたら → noteのプロフィールURLを入力
4. 審査（通常1〜3日）→ 承認されたら本番リンクが作れるようになる

### 注意点
- 初月は「紹介料の支払い対象」になるまでに180日以内に3件の成約が必要
- 商品価格の2〜3%が報酬（ウイスキーは「食品・飲料」カテゴリ）
- 24時間以内に購入されれば報酬対象（カートに入れておいてもOK）

### 使い方
1. Amazonで紹介したいウイスキーを検索
2. 上部の「SiteStripe」バーから「リンクを作成」→ 短縮URLをコピー
3. note記事に貼り付け

## 2. 楽天アフィリエイト

### 登録手順
1. https://affiliate.rakuten.co.jp にアクセス
2. 楽天IDでログイン
3. 審査即時 or 1〜2日で承認

### 使い方
- Amazonで扱っていない銘柄の補完として使う
- 楽天市場ならではの限定品・並行輸入品に強い

---

## 3. Amazonアソシエイト（米国）— 外貨用

### 登録手順
1. https://affiliate-program.amazon.com にアクセス
2. Amazon.comアカウントでログイン（日本のとは別に作る）
3. 英語ブログのURLが必要 → 英語で発信する準備ができてから登録

### 使いどころ
- 英語版note的プラットフォーム（Medium等）で英語発信する場合
- Xの英語アカウントでリンクを貼る場合
- 報酬はドルで支払われる（Payoneer経由で日本の口座に）

### 支払い方法
- 小切手（非推奨）／Amazonギフト券／**Payoneer経由の銀行振込**（推奨）
- 最低支払額：10ドル

---

## 4. The Whisky Exchange アフィリエイト（英国）— 外貨用

### 概要
- 世界最大級のウイスキー通販サイト
- 報酬率：約5%（Amazonより高い）
- 世界中に発送（日本含む）

### 登録手順
1. https://www.thewhiskyexchange.com 下部の「Affiliates」リンク
2. AWIN（欧州のASP）経由で提携
3. AWINに登録 → The Whisky Exchangeの案件に申請

### ポイント
- ジャパニーズウイスキーの品揃えも豊富
- 単価が高いので、1成約で数千円の報酬も
- 英語コンテンツとの相性が良い

## 5. リンク管理のコツ

### 絶対にやること
- どの記事にどのアフィリエイトリンクを貼ったか記録する
- 月1回、クリック数と成約数をチェック
- 伸びてる記事のリンクを増やす、伸びない記事は差し替える

### アフィリエイトリンク管理表（テンプレート）

| 記事タイトル | 対象銘柄 | Amazonリンク | 楽天リンク | Whisky Exchange | 貼付日 | 月間クリック | 成約 |
|-------------|---------|-------------|-----------|-----------------|--------|-------------|------|
| | | | | | | | |

## 6. 外貨の受け取り方

### 必要なもの
- Payoneerアカウント（無料）: https://www.payoneer.com
- 日本の銀行口座

### 流れ
1. Payoneer登録（日本語対応）
2. 米国/英国の支払い受取口座が発行される
3. Amazon.comやAWINの支払い先をPayoneerに設定
4. 一定額溜まったら日本の銀行口座に送金（手数料 約2%）

---

## 注意事項
- アフィリエイトリンクであることは必ず明記（景品表示法）
- 「絶対おすすめ」「No.1」などの誇大表現は避ける（薬機法・景表法）
- 自分で購入していないものは「実際に飲んでいません」と正直に書く
