# レーダーチャート作成ガイド

## 概要
ウイスキーの味の特徴を8軸のレーダーチャートで可視化する。
noteのアイキャッチ画像として使える。文字だけより格段にクリック率が上がる。

## 使用ツール（無料）

### 方法A：AIに直接描画させる（最も簡単）
```
以下のデータをもとに、8軸のレーダーチャートを描いてください。

軸：ピート, 甘さ, フルーティ, スパイシー, オーク, スモーキー, 複雑さ, コスパ

銘柄A「山崎12年」：2, 4, 4, 2, 3, 1, 3, 5
銘柄B「白州12年」：1, 3, 4, 1, 2, 0, 2, 4

条件：
- 背景は白
- 銘柄Aは琥珀色（#D4A030）、銘柄Bは青緑色（#20B2AA）
- 凡例をつける
- 日本語の軸ラベル
- 画像として出力
```

### 方法B：Canva（無料プラン）
1. Canvaにログイン
2. 「グラフ」→「レーダーチャート」を選択
3. データを手入力
4. デザイン調整 → PNGで書き出し

### 方法C：Chart.js（コーディング不要）
1. https://www.chartjs.org のサンプルをコピー
2. データ部分だけ書き換え
3. ブラウザで開いてスクリーンショット

## レーダーチャートのベストプラクティス

### 使うべき8軸
```
ピート感　　：ピート（スモーキーな土っぽさ）の強さ
甘さ　　　　：バニラ・キャラメル・蜂蜜のような甘み
フルーティ　：リンゴ・洋梨・柑橘系の果実感
スパイシー　：シナモン・ナツメグ・胡椒のような刺激
オーク感　　：樽由来の木の風味・タンニン
スモーキー　：焚き火・燻製のような煙っぽさ
複雑さ　　　：味わいの層の多さ・変化の豊かさ
コスパ　　　：価格に見合った満足度
```

### デザインルール
- 色は2色以内
- 背景は白または薄いグレー
- 線は太め（見やすさ重視）
- フォントはゴシック系
- 画像サイズ：幅1200px × 高さ1200px（正方形）

### 比較モード（2本比較のとき）
- 2本を重ねて描く → 「どっちを買うか」を視覚的に決められる
- 半透明で塗りつぶす（重なった部分が見える）

## 各スコアの目安

| スコア | 意味 |
|--------|------|
| 0 | ほぼ感じない |
| 1 | わずかに感じる |
| 2 | 控えめにある |
| 3 | はっきり感じる |
| 4 | かなり強い |
| 5 | 突出して強い |

## 実際の作成例

### Whiskybaseデータからスコアを抽出するAIプロンプト
```
以下のWhiskybaseテイスティングノート（複数レビューを集計したもの）をもとに、
8軸のレーダーチャート用スコア（0〜5）を抽出してください。

軸：ピート, 甘さ, フルーティ, スパイシー, オーク感, スモーキー, 複雑さ, コスパ

テイスティングノート集計：
[複数レビューのテキストを貼り付け]

出力形式：
銘柄名：数値, 数値, 数値, 数値, 数値, 数値, 数値, 数値
```
