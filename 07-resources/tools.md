# 使えるツール一覧

すべて無料または無料プランあり。

## AI
| ツール | 用途 | URL |
|--------|------|-----|
| Claude | 記事生成・翻訳・データ可視化指示 | claude.ai |
| ChatGPT | 同上（Claudeが使えない時のサブ） | chatgpt.com |
| DeepL | テイスティングノートの下訳 | deepl.com |

## 画像・デザイン
| ツール | 用途 | URL |
|--------|------|-----|
| Canva | レーダーチャート、アイキャッチ画像 | canva.com |
| Remove.bg | ボトル画像の背景透過 | remove.bg |
| Figma | 凝ったグラフ・図解（やや難） | figma.com |

## データ収集
| ツール | 用途 | URL |
|--------|------|-----|
| Whiskybase | メインデータソース | whiskybase.com |
| Reddit | 口コミ・トレンド収集 | reddit.com/r/whisky |
| Google Trends | 検索トレンド分析 | trends.google.com |

## 投稿管理

|--------|------|-----|
