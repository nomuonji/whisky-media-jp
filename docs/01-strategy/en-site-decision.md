## なぜ `/en/` ではなく別サイトなのか

### 1. 翻訳ではなく、逆ベクトルだから（最大の理由）

| | 日本語サイト | 英語サイト |
|---|---|---|
| ポジション | 「Whiskybaseの日本語フロントエンド」 | 「日本から見たジャパニーズウイスキー」 |
| 対象 | **世界のウイスキー** → 日本語読者 | **ジャパニーズウイスキー** → 英語圏読者 |
| 銘柄構成 | 日本20・スコッチ50・バーボン20・その他10 | ほぼ全部ジャパニーズ |

**現在の123銘柄のうち、英語側で必要なのは20件前後しかない。**
逆に英語側で必要な銘柄（限定品・蒸留所限定・終売品）は日本語側に無い。

→ hreflang で対応づけられるページがほとんど存在しない。
「同じ内容の言語違い」ではないので、`/en/` の構造が意味を持たない。

### 2. 共有できるドメイン資産がゼロ

現状 `whisky-media-jp.pages.dev`。独自ドメイン未取得（`site-todo.md` §4）。
「`/en/` にすればドメイン評価を共有できる」という通常の利点は、**共有元が無い。**

### 3. 収益導線が別物

| | 日本語サイト | 英語サイト |
|---|---|---|
| 主導線 | Amazon JP **4.00%**（食品&飲料、お酒） | **AWIN経由の英国系専門EC** |
| 補完 | 楽天アフィリエイト | Hard to Find Whisky 6%／クッキー30日 |
| 使えないもの | — | **Amazon US（酒類 0%）** |
| 通貨・受取 | 円 | ポンド → Payoneer（JPY建て決済に対応） |

リンク管理・開示表記・レポートが完全に分かれる。同一サイトに混ぜると運用が複雑になるだけ。

### 4. コンプライアンスが別物

- 日本語側：景表法・薬機法の表現規制、アフィリエイト表記
- 英語側：FTC disclosure、英語圏の年齢確認、各国の酒類広告規制

1ドメインに同居させると、両方の最も厳しい要件を全ページに適用することになる。

## 共有するもの（ここに効率がある）

monorepo にして、**データとコンポーネントだけ**共有する。

```
whisky/
├── packages/
│   ├── data/          銘柄・蒸留所・8軸スコア（言語非依存の数値）
│   └── ui/            RadarChart / ScoreDistribution / 価格×スコア散布図 / OGP生成
├── site-ja/           Whisky Data JP（既存）
└── site-en/           新規
```

- **数値（8軸スコア・熟成年数・度数・Whiskybaseスコア）は言語非依存**なので完全共有できる
- **テイスティングノートと記事本文は共有しない**（翻訳ではなく別に書く）
- チャート実装は既に5種ある。ここの再利用が最大の節約になる

## 英語サイトだけの差別化

既存の英語ニッチ4サイト（sipjapan / dandijapan / thewhiskymasters / kanpai-navi）が
持っていないものを1点に絞る。

> **日本での実売価格と入手可否。**

ジャパニーズウイスキーは配分（allocation）市場で、日本国内価格と海外価格が乖離している。
英語圏の読者が最も知りたく、**英語圏のライターが構造的に書けない**のがここ。
`whisky-media-jp` が既に持っている価格データの延長線上にある。

**非目標**：世界のウイスキー全般（日本語サイトの領分）、テイスティングの主観描写。

## 順序についての注意

**週2時間の制約下で、2サイトを同時に前に進めるのは無理。**

現状、日本語サイトは v1 達成（銘柄123・蒸留所54・チャート5種）だが、
`site-todo.md` §4 が未了で **アフィリエイトリンク7件が全部プレースホルダ**。
つまり**既に作った資産から1円も回収していない。**

§4 は全部が設計判断の要らない事務作業なので、先に潰すと：

- 既存資産が即座に収益化される（最も安い改善）
- 「本当に成約するのか」がAmazon JP 4%で検証できる
- その結果を持って英語サイトに投資できる

英語側を先に始める合理性もある（単価が高い・競合LOW・外貨目標に直結）が、
**両方同時は選ばない。**
