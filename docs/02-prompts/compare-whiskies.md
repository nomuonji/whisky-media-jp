# AIプロンプト：ウイスキー比較記事

## 使い方
1. 比較したい2本のウイスキーの情報（Whiskybaseのデータ）を用意
2. 以下のプロンプトに情報を貼り付け
3. AIが比較表＋レーダーチャート用データ＋本文を生成
4. 出力からレーダーチャート用データを可視化ツールに渡す

---

## プロンプト

```
あなたはウイスキージャーナリストです。以下の2本のウイスキーを比較する記事を、データドリブンな視点で書いてください。

## 出力フォーマット

### 1. 比較表（Markdownテーブル）
| 項目 | ウイスキーA | ウイスキーB |
|------|-----------|-----------|
| 銘柄名 | | |
| 蒸留所 | | |
| 種類（シングルモルト等） | | |
| 熟成年数 | | |
| アルコール度数 | | |
| 価格帯（希望小売） | | |
| Whiskybase平均点 | | |
| ピートレベル（1-5） | | |
| 主な香りの特徴 | | |
| おすすめの飲み方 | | |
| こんな人にオススメ | | |

### 2. レーダーチャート用データ（5段階評価）
ピート, 甘さ, フルーティ, スパイシー, オーク, スモーキー, 複雑さ, コスパ

ウイスキーA: [数値をカンマ区切りで。例: 2,4,3,2,3,1,3,5]
ウイスキーB: [数値をカンマ区切りで]

### 3. 本文（800〜1,200文字）
- 導入：この2本を比較する理由（例：同じ価格帯、同じ産地、初心者に人気）
- 香りの比較（2〜3文）
- 味わいの比較（2〜3文）
- 余韻の比較（1〜2文）
- 結論：どんな人にどちらを勧めるか（2〜3文）
- アフィリエイト向け誘導文（1文：「どちらもAmazonで購入できます。詳細は記事末尾のリンクから」）

### 4. キャッチコピー（30文字以内）
例：「山崎 vs 白州、あなたに合うのはどっち？」

### 5. X投稿用（200文字以内）
noteのリンクを貼る前提の、クリックしたくなる要約文。絵文字1〜2個使用可。

## スタイル
- です・ます調
- 主観だけでなくデータ（点数、価格）を必ず入れる
- 「おすすめ」で終わらせず、読者の好み別に選べるようにする
```
