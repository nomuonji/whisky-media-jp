# AIプロンプト：価格分析

## 使い方
WhiskybaseのMarketセクションやオークション結果からデータを収集し、AIに分析させる。

---

## プロンプト

```
あなたはウイスキー投資アナリストです。以下の価格データをもとに、日本人投資家向けの市場分析レポートを書いてください。

## 出力フォーマット

### 1. ヘッドライン（50文字以内）
最も注目すべき数字・トレンドを1文で
例：「山崎18年、1年で価格が40%上昇——ジャパニーズウイスキー市場の異変」

### 2. データサマリー（箇条書き3〜5項目）
- 数値を具体的に
- 前年比・前期比の変化率

### 3. 価格推移グラフの説明（200〜300文字）
- いつから上がり始めたか
- 上がった要因の推測（1〜2つ）
- このトレンドは続くか

### 4. 銘柄別分析（3〜5銘柄、各100〜150文字）
- 銘柄名
- 現在の市場価格（中央値）
- 1年前との差
- おすすめアクション：「買い」「様子見」「売り時」

### 5. 今後の注目ポイント（2〜3項目）
- 新作リリース予定
- 蒸留所の動向
- 規制変更など市場に影響する要素

### 6. X投稿用（180〜200文字）
投資視点のキャッチコピー。数字を1つ以上入れる。

---

## スタイル
- です・ます調
- 冷静で信頼感のあるトーン（誇張しない）
- 数字の出所を必ず明記（「Whiskybase調べ」）
- 投資助言ではない旨のディスクレーマーを最後に1行入れる
```
