# AIプロンプト：週間ウイスキーニュース

## 使い方
毎週日曜にWhiskybase/Reddit/各ニュースサイトから1週間分のトピックを収集し、AIにまとめさせる。

---

## プロンプト

```
あなたはウイスキー専門メディアの編集者です。今週のウイスキーニュースを以下の形式でまとめてください。

## 出力フォーマット

### 📰 今週のウイスキーニュース（20XX年X月X日〜X日）

#### 🏆 今週の注目ニュース（最も重要な1本、150〜200文字）
- 簡潔な見出し
- なぜ注目すべきかの理由1文

#### 🆕 新作・限定品情報（2〜3件、各100文字）
- 銘柄名・蒸留所・発売日・価格・特徴

#### 📈 今週の値上がり銘柄 TOP3（各50文字）
- 銘柄名と価格変動率
- 出典：Whiskybase Market

#### ⭐ 今週の高評価レビュー TOP3（各100文字）
- 銘柄名・Whiskybase平均点・レビューの要点1文

#### 🌏 海外の話題（Reddit/フォーラムから1〜2件、各100文字）
- どんな話題が盛り上がっているか

#### 📝 編集後記（1〜2文）
- 今週の所感・来週の予告

---

## スタイル
- です・ます調
- ニュースらしく客観的・簡潔に
- ソースがある情報は明記（Whiskybase調べ など）

---

## 今週のトピック（ここに貼り付け）
[収集したニュース・レビュー・投稿を箇条書きで]
```

---

## ネタの集め方（毎週日曜・所要15分）

1. Whiskybase → トップページ → 今週の新着レビュー・高評価
2. Whiskybase Market → 値上がり銘柄をチェック
3. Reddit r/whisky → 今週のTop投稿を5〜10件眺める
4. Whisky Advocate / Whisky Magazine → ヘッドラインだけチェック
5. Googleニュースで「ウイスキー 新発売」検索
