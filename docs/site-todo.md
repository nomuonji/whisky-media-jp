# サイトを「データメディア」にするための残タスク

> **現在地（2026-08-06）**：v1（サイトとして成立）はすべて達成。
> 銘柄123件・蒸留所54件・実写真49件・チャート5種。残りはv2（公開）とv3（差別化）の事務作業。
> 詳細は `site-requirements.md` §7。

## 根本の問題（解決済み）

サイトの単位が **記事しかない**。
「データで読むウイスキー」を名乗るのに、データの単位である**銘柄ページ・蒸留所ページが存在しない**。

これが3つの症状すべての原因になっている。

| 症状 | 原因 |
|------|------|
| データが足りない | 銘柄が `data/whiskies.ts` に7件手書きされているだけ。20万本どころか7本 |
| コンテンツが見つけにくい | 入口が「新着記事」「カテゴリ」「タグ」の3つだけ。全部**記事の入口**で、銘柄から探せない |
| 視覚的に面白くない | 可視化できるデータが無い。チャートはレーダー1種類、しかも3記事中1記事にしか出ない |

**記事は在庫が増えないと価値が出ないが、銘柄DBは1回作れば全ページの燃料になる。**
ここを最初にやる。

# 1. データが足りない

## 1-1. 銘柄コレクションを作る（最優先）

`data/whiskies.ts`（7件・8項目）を、コレクション化して数百件に育てる。

```
src/content/whiskies/yamazaki-12.md   ← またはJSON一括
```

持つべき項目：

| 分類 | 項目 |
|------|------|
| 基本 | 銘柄名 / 英語名 / 蒸留所 / 国 / 地域 / タイプ / 熟成年数 / 度数 / 樽 / ボトラー |
| 評価 | Whiskybaseスコア / レビュー数 / 自社スコア |
| 味 | 8軸スコア（ピート・甘さ・フルーティ・スパイシー・オーク・スモーキー・複雑さ・ボディ） |
| 価格 | 参考価格（円）/ 現地価格 / 価格帯タグ / 入手性 |
| 導線 | アフィリID / 関連記事 / 似ている銘柄 |

- [ ] スキーマ定義（`content.config.ts` に `whiskies` コレクション追加）
- [ ] **初期100銘柄**を投入（日本20・スコッチ50・バーボン20・その他10）
- [ ] `/whisky/[slug]` ページを作る ← **これがサイトの資産の本体になる**
- [ ] 記事から銘柄を参照（記事内に銘柄カードを差し込む）／銘柄から関連記事へ相互リンク

## 1-2. 蒸留所コレクション

# 2. コンテンツが見つけにくい

現状の入口は「トップの新着リスト」「カテゴリ5個」「タグ」「検索（フッターのみ）」。
**読者は「記事」を探しに来るのではなく「どれを買うか」を探しに来る**ので、軸が合っていない。

## 2-1. 銘柄を探すUI（新規）

- [ ] **`/whiskies/` 一覧＋絞り込み** — 価格帯 / タイプ / 国・地域 / ピート / スコア / 熟成年数
- [ ] **ソート** — 安い順 / スコア順 / コスパ順（1点あたり価格）
- [ ] **予算で選ぶ** — `/budget/3000/` `/budget/5000/` `/budget/10000/`（検索需要が大きい）
- [ ] **味で選ぶ** — `/flavor/peaty/` `/flavor/sweet/` `/flavor/fruity/`
- [ ] **地域で選ぶ** — `/region/islay/` `/region/speyside/` `/region/japan/`

## 2-2. 比較・レコメンド（サイトの目玉になる）

- [ ] **比較ツール `/compare/`** — 任意の2〜4本を選ぶとレーダーが重なる。URLで共有可（`/compare/?a=yamazaki-12&b=hakushu-12`）
- [ ] **「◯◯が好きならこれ」** — 8軸スコアの距離で類似銘柄を出す（`plan.md` のタイプE。実装が無いので今は書けない）
- [ ] 銘柄ページに「この価格帯の他の選択肢」「同じ蒸留所の別ボトル」

## 2-3. ランキング（回遊と流入の両方に効く）

- [ ] `/ranking/cospa/` コスパTOP50
- [ ] `/ranking/score/` 高評価TOP50
- [ ] `/ranking/beginner/` 初心者向けTOP20
- [ ] 価格帯別ランキング（〜3000円 / 〜5000円 / 〜1万円）

## 2-4. 既存の導線の穴

- [ ] 検索がタイトルと抜粋しか見ていない → 本文・銘柄名・蒸留所名も対象に
- [ ] 検索の入口がフッターだけ → ヘッダーに検索を置く
- [ ] カテゴリ一覧 `/category/` とタグ一覧 `/tag/` のページが無い
- [ ] 用語集コレクション（本文の専門用語から自動で内部リンク）
- [ ] トップが新着の縦積みだけ → 「探す入口」を並べたトップに再設計

# 3. 視覚的な面白さがない

今あるビジュアル資産は**レーダーチャート1種類だけ**。しかも3記事中1記事にしか出ない。
文字と表だけのページが続いている。

## 3-1. 「データメディアらしい絵」を作る

- [ ] **価格 × スコアの散布図** — コスパの良い銘柄が一目で分かる。このサイトの看板になる絵
- [ ] **価格推移グラフ**（`whisky/PriceGraph.astro`）
- [ ] **蒸留所マップ** — スコットランド地域図・日本地図に蒸留所をプロット。クリックで蒸留所ページへ
- [ ] **フレーバーホイール** — 円形で味の分布
- [ ] **地域 × フレーバーのヒートマップ** — 「アイラは本当にピーティか」を1枚で示す
- [ ] **スコア分布のヒストグラム** — 「80点は上位何%か」 ✅ 実装済み（`ScoreDistribution.astro`。各銘柄ページとランキングに表示）
- [ ] **蒸留所の系統図・年表**

## 3-2. 一覧・記事の見た目

- [ ] **アイキャッチが1枚も無い** — 記事一覧が完全に文字だけ。最低でも銘柄名＋琥珀グラデの自動生成画像
- [ ] **OGP画像の自動生成**（satori等）— 銘柄名＋スコア＋ミニレーダー。シェア時の見栄えが変わる
- [ ] 銘柄カードに**ボトルのシルエットSVG**と、地域・タイプ別のカラーコード
- [ ] 比較表の★文字列（`★★★☆☆`）を**バー表示**に

- [ ] 写真素材の方針を決める（自前撮影 / フリー素材 / 使わず図解で通す） ✅ **Wikimedia CommonsのCCライセンス写真49枚を導入済み**
  - 取得方法は `article-material-research` スキルの `commons_image.py`／カテゴリAPIでライセンス確認 → ローカル配信

## 3-3. サイト全体のトーン

- [ ] トップのヒーローが絵文字1つ＋テキスト。**動きのあるデータビジュアル**を置く
- [ ] ダークモード（琥珀色はダークで映える）

# 着手順（推奨）

```
Step 1  銘柄コレクションのスキーマ設計 + 初期30銘柄 + /whisky/[slug] ページ
Step 2  一覧＋絞り込み /whiskies/ と ランキング（コスパ・高評価）
Step 3  価格×スコアの散布図、比較ツール /compare/
Step 4  銘柄を100件に増やす、蒸留所30件 + マップ
Step 5  OGP自動生成とアイキャッチで一覧の見た目を作る
```

Step 1〜3 まで進むと、記事が3本のままでも**サイトとしては成立する**（銘柄30ページ＋ランキング＋比較ツール）。
記事はその後で増やせばよい。
